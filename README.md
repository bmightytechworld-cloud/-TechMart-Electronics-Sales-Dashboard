## TechMart Electronics Sales Dashboard

## Client Request
US electronics retail store managing sales across 
4 states needed 3 disconnected sheets cleaned, 
merged and automated with a full performance 
dashboard.

## Problems Found
- Duplicate transactions across sales sheet
- Inconsistent sales rep names throughout
- Mixed date formats across all rows
- Inconsistent state names
- Inconsistent product codes
- Missing revenue on 14 transactions
- Missing quantity on multiple rows
- Product and customer data in separate sheets

## What I Fixed
- Removed all duplicates
- Standardized all names, states and product codes
- Unified all date formats
- Calculated all missing revenue automatically
- Calculated profit per transaction
- Merged product database using Product ID
- Merged customer database using Customer ID
- Built pivot view — revenue by state per category
- Built input sheet with dropdown validation
- Built summary dashboard with charts

## Deliverables
- Sheet 1 — Raw Sales Transactions
- Sheet 2 — Raw Product Database
- Sheet 3 — Raw Customer Database
- Sheet 4 — Master Sales Table
- Sheet 5 — Pivot View
- Sheet 6 — Input Sheet
- Sheet 7 — Summary Dashboard
